Forecasts Roblox's Up-and-Coming top 10 for the next 72 hours as honest per-place probabilities: an ensemble of a drift-diffusion rank model and an empirical rank-transition table conditioned on 24h playing growth, validated walk-forward on the public chart archive.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
